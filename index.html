Lull Fan

A fan-noise sleep aid for iPhone. Every sound is generated live rather than looped, so nothing repeats over an eight-hour night, and the speed switch changes the character of the sound the way a real fan's pitch changes with its motor.

Gym Logbook Pro

A weightlifting logbook for iPhone. Everything is written to the device first, so a session keeps logging in a basement gym with no signal, and each exercise opens with what you actually lifted last time — duplicate the set or apply the previous numbers instead of typing them again. Personal records and estimated 1RM update as you go.
